# Downstream Semantics And Evidence Boundaries

This page defines what downstream outputs mean. Use it before writing a
biological narrative or a paper section.

For implementation details, do not rely on prose alone. Check
`api-reference.md` for package source paths, required input fields, array
shapes, return payloads, side effects, and artifacts. If a claim depends on
array axes, projection mode, or a generated payload field, verify it against
the current source and record that provenance in the analysis manifest.

## 1. Active Objects

Keep these objects separate:

- **trained model**: neural velocity/growth/score/interaction fields from a
  completed training run or final regression;
- **active AnnData**: observed cells and metadata, usually with `X_latent` and
  `time_point_processed`;
- **evaluation trajectory**: sealed rollout artifact generated by the trained
  model for evaluation metrics;
- **downstream trajectory dataset**: additional rollout artifact generated for
  biological interpretation;
- **diagnostic fields**: local velocity, stream embeddings, growth summaries,
  Jacobians, or driver scores.

Narrative claims should cite the right object. For example, a stream plot is a
local flow diagnostic, not proof of a simulated single-cell path.

## 2. Continuous Dynamics

CytoBridge learns continuous dynamics. Valid continuous-time evidence includes:

- final-regression `EvaluationTrajectory`;
- toolkit `generate_trajectory_dataset(...)` output;
- `tl.downstream.generate_ode_trajectory_bundle(...)`;
- `tl.downstream.generate_sde_trajectory_bundle(...)`;
- matched control/perturbed rollouts from the trained model.

For intermediate-time or per-cell path claims, prefer an existing locked
evaluation trajectory if it matches the active model and data. Otherwise
generate a new trajectory dataset and save the script and manifest.

## 3. Fate And Lineage

Fate and lineage labels are not interchangeable.

Valid readout contracts include:

- terminal fate labels documented in the dataset;
- lineage or barcode descendants documented in preprocessing/metadata;
- a frozen classifier and its metadata;
- explicit user-defined target groups.

If no readout contract exists, report endpoint neighborhoods, branch geometry,
or state structure as exploratory. Do not call it fate truth.

For branching systems, report distributions over fates/lineages when possible.
Top-1 fate alone is usually too weak.

## 4. Growth And Mass

CytoBridge growth field semantics are:

```text
g(t, x) = d/dt log w
```

This is a growth rate, not an absolute population count. Empirical cell counts
by time are observed sampling/count diagnostics. Model mass claims require a
trained growth/mass mechanism or explicit rollout weights.

Balanced-only models may still provide useful state dynamics and empirical
count diagnostics, but do not claim mechanistic unbalanced mass recovery unless
the model actually represents mass dynamics.

## 5. Perturbation

Perturbation claims require matched control and perturbed simulations from the
same trained model, source population, time span, and readout.

Record:

- perturbed genes or latent factors;
- perturbation magnitude and feature space;
- source cells and time span;
- control rollout artifact;
- perturbed rollout artifact;
- readout: fate shift, endpoint shift, growth change, driver response, or
  trajectory displacement.

Static expression differences or metadata contrasts are useful context but are
not model-simulated perturbation effects.

## 6. Gene-Level Claims

Gene-level claims require one of:

- measured gene-space computation;
- valid PCA/loading projection from latent space;
- explicit gene-space perturbation/readout path;
- documented feature mapping for driver scores.

If the output is latent-only, describe it as latent factors or state-space
drivers unless a projection is valid and saved.

## 7. Claim Strength Labels

Use these labels in downstream reports:

- **locked evidence**: final-regression/evaluation artifact from completed
  algorithm lifecycle;
- **model-native downstream evidence**: additional saved rollout or package API
  computation from a trained model;
- **diagnostic evidence**: local velocity, stream, Jacobian, or static summary;
- **hypothesis**: plausible biological interpretation needing validation;
- **limitation**: missing metadata, weak projection, no classifier, or failed
  analysis.

Do not mix these labels in final claims.
