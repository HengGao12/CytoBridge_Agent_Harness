# High-Tier Figure Contact Sheets

These contact sheets are stored here as a quick visual reference for main-result-page layout.

They were generated from local PDFs audited for the shared figure template library.

## Files

- `high_tier_page_audit_20paper_contact_sheet.png`
  - combined 20-paper result-page audit
- `all_local_pdf_contacts.png`
  - core set of local high-tier papers
- `extra_local_pdf_contacts.png`
  - additional published pages used to widen the page-skeleton sample

## Intended Use

Use these only as **visual audit references**:

- to compare page skeletons
- to inspect how published pages allocate space
- to remind yourself what a strong hero zone or support zone looks like

Do not treat them as style targets to copy literally.

The goal is to learn:

- page skeleton
- zone hierarchy
- hero object weight
- grammar transitions

not to imitate one paper's exact canvas.
