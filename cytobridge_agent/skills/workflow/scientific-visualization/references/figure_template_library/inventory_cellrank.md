# CellRank Figure Inventory

This note records what `CellRank` contributes to the template library.

## Public Sources

- CellRank Nature Methods paper
- CellRank Nature Protocols paper
- CellRank official docs:
  - fate probabilities tutorial
  - gene trends tutorial

## Why It Matters

`CellRank` is the strongest public source for missing **lineage / fate trend** templates.

## Strongest Template Targets

## 1. Aggregate fate-probability panel

Use for:

- cluster-level or cohort-level fate support
- supplement fate summaries

Decision:

- often acceptable as a native-plot wrapper

## 2. Gene trends along lineages

Use for:

- lineage-weighted gene dynamics
- mechanism support along branching decisions

Decision:

- high-value source for a future `lineage_trends` template

## 3. Fate-coupled heatmaps

Use for:

- ranked genes correlated with a lineage/fate axis

Decision:

- support/supplement template rather than default anchor panel

## Net Value

CellRank is the best public source for filling:

- fate-probability summaries
- lineage gene trends
- fate-coupled dynamic support panels
