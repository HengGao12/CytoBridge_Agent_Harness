# Downstream Skills

Use this domain only through `workflow/downstream-analysis` after a trained
model exists and the task needs a narrow biological analysis module.

This domain is not an evaluator file-contract layer. Fixed external submission
schemas belong to the corresponding task runner or export tool, not to
downstream skills. Downstream skills define scientific computations, package API
selection, artifact provenance, and biological interpretation.
